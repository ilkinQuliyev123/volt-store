# ⚡ Volt — Electronics Store (demo)

A clean, responsive e-commerce storefront built with **Next.js (App Router), TypeScript and Tailwind CSS**.

**Features:** category navigation, search, sorting, product pages, persistent cart (localStorage), checkout flow with order confirmation, fully responsive.

> Demo project: products are fictional and no payments are processed.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.
